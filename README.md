## 🧩 Common problems

### The app does not open

- Make sure you downloaded the Windows file from the release page.
- Check that the download finished.
- Try opening the file again.
- Restart your PC and try once more.

### Windows blocks the app

- Right-click the file.
- Choose Properties.
- Look for an Unblock box and select it if shown.
- Try opening the app again.

### The QR code looks blurry

- Use a larger image size.
- Save as PNG if that option exists.
- Start with short text or a short link.

### The scan result is empty

- Check that the image contains a clear QR code.
- Make sure the code is not cut off.
- Try a sharper image with better light.

## 🧪 Best results

Use short text when you can. Short content makes QR codes easier to scan.

For printed QR codes:

- leave space around the code
- use high contrast colors
- avoid stretching the image
- test the code before sharing it
